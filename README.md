## 🌍 The StitchFlow Vision

In vibrant fashion capitals across Africa—from **Nairobi's Kilimani salons** and **Lagos Island's Agbada workshops** to **Accra's Kente weaving compounds** and **Johannesburg's bespoke studios**—fashion entrepreneurs manage high-value bespoke commissions. Yet their daily operations are fragmented across chaotic WhatsApp voice notes, paper tape measure ledgers, and lost fabric swatch references.

**StitchFlow** bridges this gap. It replaces manual ledgers with an authentic, culture-first SaaS platform designed strictly around African sartorial traditions:

* **No Eurocentric concessions:** Built from the ground up for **3-Piece Royal Agbadas, Modern Senator Suits, Kenyan Ruracio Kitenge Bridal Corsetry, Swahili Coastal Kanzus, and Bonwire Kente Capes**.
* **Specialized African Measurement Cards:** Captures Agbada wrist-to-wrist wingspans, ceremonial robe drops, Sokoto trouser tapers, and matching hand-sewn Fila cap circumferences.
* **Smartphone-First for Workshop Floors:** Tailors chalking patterns and pressing seams operate the entire workflow via 44px+ touch targets on mobile devices.
* **WhatsApp Deep Integration:** Seamless click-outs and pre-filled consultation queries since African commerce lives on WhatsApp.

## 💎 Four Role-Based Operating Suites

StitchFlow features an instant role switcher in the primary navigation, accommodating the four foundational personas in bespoke fashion:

```
┌────────────────────────────────────────────────────────────────────────┐
│                        STITCHFLOW ATELIER ROLES                        │
├───────────────────┬───────────────────┬────────────────┬───────────────┤
│ 🌐 Public Visitor │ 👑 Atelier Owner  │ ✂️ Tailor Bench│ 👗 VIP Patron │
│  African Lookbook │  Executive KPIs   │ Mobile Touch Q │  Order Status │
│  Ceremony Booking │  Kanban Pipeline  │ Agbada Metrics │  Feedback Loop│
│  Garment Tracker  │  Bench Allocation │ 1-Click Stepper│  Referral Eng │
└───────────────────┴───────────────────┴────────────────┴───────────────┘
```

### 1. 🌐 Public Lookbook & Cultural Booking Engine (Anonymous Visitor)
- **High-Res Digital Lookbook:** Filter across *Grand Agbada & Boubou*, *Senator Suits & Kaftans*, *Ceremonial & Bridal*, *Modern Kitenge & Wax*, and *Heritage Tunics & Kanzu*.
- **Textile Provenance Badges:** Highlighting authentic origins including Vlisco Hollandais Wax, Nigerian Aso-Oke, Ghanaian Bonwire Kente, Malian Bògòlanfini (Mudcloth), and Kenyan Kikoy.
- **Interactive Multi-Step Booking Engine:**
  - *Step 1:* Cultural service (Traditional Wedding / Ruracio, Grand Agbada Sizing, Senator Kaftan Fitting, Wax Swatch Selection).
  - *Step 2:* Master artisan selection (Amani Mutiso, Kofi Mensah, Zari Odhiambo).
  - *Step 3:* Interactive calendar with **anti-double-booking locks**.
  - *Step 4:* Patron details, event theme colors, and fabric provision status.
- **Fast Garment Tracker Bar:** Instant lookup by Order ID (e.g. `ORD-892`, `ORD-893`) or phone number without requiring sign-in.
- **Floating WhatsApp Anchor:** Pre-filled inquiry prompts with &lt;15 min atelier response indicators.

### 2. 👑 Atelier Director & Owner Suite (`OwnerDashboard`)
- **Executive Financial Counters:** Realized revenue (KES / USD toggle), pending ceremonial balances, workshop capacity %, and consultation queues.
- **Artisan Workload Distribution:** Live bench capacity gauges across master cutters, embroiderers, and bridal finishers.
- **4-Phase Production Kanban:** Real-time garment board (`cutting` ➔ `stitching` ➔ `fitting` ➔ `ready`).
- **New Commission Logger:** Log new client garments with fabric specifications, target event deadlines, deposits, and remaining balances.
- **Digital Measurement Archive:** Comprehensive directory of VIP clients and their saved dimensions.
- **Lookbook CMS:** Publish new bespoke creations directly to the public showcase.

### 3. ✂️ Master Artisan Bench (`TailorDashboard`)
- **Smartphone-First Mobile Queue:** Engineered for tailors standing at cutting tables and steam presses.
- **Artisan Persona Switcher:** Switch between Master Pattern Cutter, Senior Tailor, and Bridal Finisher.
- **1-Click Stage Stepper:** Instant garment progression with single-tap triggers.
- **Digital Anatomical Measurement Card:**
  - Standard dimensions: Chest, Waist, Hips, Length, Sleeve, Shoulder, Inseam, Neck.
  - African dimensions: **Agbada Wingspan**, **Fila Cap Circumference**, and **Drape / Posture Ease Notes**.
- **Artisan Bench Note Logger:** Record fabric shrinking, chalk lines, and fitting adjustments with automatic timestamps.

### 4. 👗 VIP Patron Portal (`ClientPortal`)
- **Live Garment Milestone Tracker:** Real-time visual progress stepper with assigned artisan and target handover dates.
- **Saved Anatomical Profile:** Inspect verified measurements and submit adjustment requests.
- **Post-Delivery Feedback Loop:** 1–5 star rating, fit assessment (*Tight / Perfect Bespoke / Loose*), and review submission to the creative director.
- **Viral Cultural Referral Loop:**
  - Unique referral link & code (e.g., `STITCH-NYAMBURA-20`).
  - *"Give your friends KES 3,000 off their first bespoke fitting, get 15% credit on your next garment."*
  - 1-tap WhatsApp share button and real-time conversion counter.

## 🎨 Design System & Token Architecture

StitchFlow uses **W3C Design Token Community Group (DTCG)** formatting and CSS Custom Properties with zero hardcoded hex values in core components.

### 🎨 Color Palette & Cultural Story

| Token Name | CSS Custom Property | Value | Cultural Meaning |
|---|---|---|---|
| **Ebony Obsidian** | `--sf-color-ebony` | `#161311` | Carved African ebony sculptures & deep formal contrast |
| **Savannah Gold** | `--sf-color-gold` | `#D4A347` | Ghanaian gold dust & metallic brass embroidery filigree |
| **Terracotta Ochre** | `--sf-color-terracotta` | `#C25E34` | Great Rift Valley red earth & terracotta clay dyes |
| **Royal Indigo** | `--sf-color-indigo` | `#1A2639` | Yoruba Adire resist-dyed indigo textiles |
| **Raw Linen Canvas** | `--sf-color-canvas` | `#FAF6F0` | Unbleached organic cotton & woven raffia background |

### 📐 Contrast & Accessibility (WCAG 2.1 AA)
* **Body Text:** `#1A1715` on `#FAF6F0` achieves a **14.9:1 contrast ratio** (AAA compliance).
* **Secondary Text:** `#6A5D52` achieves a **5.4:1 contrast ratio** (AA compliance).
* **Focus Rings:** High-visibility keyboard focus rings (`outline: 2px solid var(--sf-color-gold)`).
* **Touch Targets:** Minimum 44x44px clickable areas on mobile viewports.

## 🛠️ Tech Stack & Architecture

* **Frontend Framework:** React 19 (Functional components, custom hooks, typed context)
* **Language:** TypeScript 5.x (Strict mode enabled)
* **Styling:** Tailwind CSS v4 (Integrated with W3C tokens & CSS Custom Properties)
* **Iconography:** Lucide Icons (Stylized with tailoring shears, needlework, and cultural badges)
* **Typography:** Cormorant Garamond (Editorial Serif) & Plus Jakarta Sans (Clean Modern Sans)
* **State Management:** In-memory reactive state synchronized with `localStorage` (100% offline-friendly, no external backend required for instant demo verification)
* **Build System:** Vite 8.x with HMR support and lightning-fast asset bundling

## 🚀 Quickstart & Development

### Prerequisites
* **Node.js:** v18.x or v20.x+
* **npm:** v9.x or v10.x+

### 1. Clone the repository
```bash
git clone https://github.com/your-username/stitchflow-atelier.git
cd stitchflow-atelier
```

### 2. Install dependencies
```bash
npm install
```

### 3. Launch the development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for production
```bash
npm run build
```

## 📱 Breakpoint Responsiveness Guide

* **320px – 480px (Mobile Workshop View):** Tested for Samsung Galaxy and Tecno devices commonly used by tailors across Nairobi and Lagos. Single column cards, 44px tap targets, bottom docked WhatsApp bar.
* **768px – 1024px (Fitting Salon iPad):** 2-column lookbook layout, split appointment calendar, side-by-side anatomical visualizer.
* **1280px+ (Atelier Back-Office):** Full 4-lane production Kanban, financial cashflow counters, and tailor bench allocation gauges.
