## Iteration failures and corrections

- The first hermetic run exited **1** because the in-memory credential handoff rejected the invitee
  password key. The allow-list was corrected; the two final complete runs each passed 6/6.
- The first restore-control trial used a one-line non-SQL file and exited **1** in self-control setup
  before reaching the dump validator. It was replaced with a real source dump truncated to 1,000
  bytes; the rehearsal then rejected it at the 20,000-byte floor with exit **1**.
- The first all-table restore self-control attempt exited **1** because a malformed archive control
  was classified as a missing-source precondition (exit 2). The precondition now occurs only after
  restore validation, so the malformed SQL control is rejected by restore with exit **1**. The final
  rehearsal passed all three self-controls and the full restore.
