# Component Brief: `<stitchflow-african-production-stepper>`

## 1. Overview
Visual tracking component specifically mapped to the lifecycle of bespoke African attire:
1. `cutting`: Fabric inspection, shrinkage, and pattern matching across authentic African wax prints (Kitenge/Ankara) or hand-woven strips (Kente, Aso-Oke, Kikoy).
2. `stitching`: Artisan tailor assembly on the workshop bench, collar structuring, and Sokoto taper.
3. `fitting`: Basted ceremonial fitting where client inspects Agbada shoulder balance, Kaftan neckline drop, or corset contour.
4. `ready`: Final hand-pressing, matching Fila cap / Gele headwrap coordination pass, and packaging for cultural events.

## 2. Shadow DOM Specification
- **Tag:** `<stitchflow-african-production-stepper>`
- **Encapsulation:** `mode: 'open'`
- **Inherited CSS Custom Properties:**
  - `--sf-color-gold`
  - `--sf-color-terracotta`
  - `--sf-color-ebony`
  - `--sf-color-canvas`
  - `--sf-color-border`

## 3. Responsive States
- Mobile (320px): Tap-friendly milestone steps with African embroidery icons.
- Tablet (768px): Timeline with estimated completion for traditional event deadlines (Ruracio, Traditional Wedding, Coronation).
- Desktop (1280px): Detailed progress drawer with photo attachments.
